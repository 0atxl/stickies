# Stickies v0.10

Local sticky notes for Windows x86_64 and supported Linux Wayland desktops. Package version: 0.10.0.

## What is included

- Edge notes on all four screen edges, detached notes, Search and All Notes.
- Local SQLite storage, checklists, inline formatting, undo/redo and per-note appearance.
- Bounded note resizing, corrected Windows note-menu stacking and strip collapse when opening a note away.
- Windows strip windows stay out of the taskbar. Detached notes and All Notes retain normal taskbar behavior.
- Save-safe Quit through Settings and the tray.

## Downloads and installation

**Windows x86_64:** extract the entire `stickies-windows-x86_64.zip`, then open `bin\stickies.exe`. Keep its runtime folders together. MSYS2 and Rust are not required. Notes and settings normally live under `%LOCALAPPDATA%\stickies`, separately from the extracted folder. Quit before replacing the bundle. Disable Launch at login before moving/removing it, or re-enable it from its new location.

**Arch Linux x86_64:** download `stickies-0.10.0-1-x86_64.pkg.tar.zst` and install it with `sudo pacman -U ./stickies-0.10.0-1-x86_64.pkg.tar.zst`. Use an up-to-date Arch system with a Wayland compositor supporting Layer Shell v4+. This is not a portable Ubuntu/Kali/Linux download. Quit before upgrading. Removing the package leaves your user notes and settings intact.

The AUR recipes are `stickies` for a source build and `stickies-bin` for the prebuilt Arch package. Cargo users can install version 0.10.0 with `cargo install stickies --version 0.10.0 --locked` after installing the native build dependencies listed in the README. Cargo installs the executable; desktop entry/icon installation is a separate documented step.

Keep the matching source archives and original notices available when redistributing these downloads. `SHA256SUMS` covers all attached release files. These builds are unsigned; checksums detect changed bytes but do not provide a publisher signature. Windows does not have an Authenticode signature.

## Verification and limits

The preceding CI candidate passed the existing Linux checks and tests, focused Arch install/reinstall/removal and note-retention checks, and owner-run Windows checks with disposable data, a system-only PATH, spaces/Unicode paths and bundle relocation. Release CI and packaging are checked again for the selected release commit before publication.

The Linux edge requires Wayland Layer Shell v4+. GNOME without Layer Shell, X11 and macOS are not supported by this release. Mixed-DPI/multi-monitor behavior, actual login/session-end behavior, upgrades from older versions, accessibility and controlled failed-save scenarios do not have complete verification. AUR and Cargo installation require compatible native libraries. No binary reproducibility claim is made.

Report problems at https://github.com/0atxl/stickies/issues with the OS/version, compositor or Windows display scaling, package version, reproduction steps and relevant error output. Remove personal note contents from logs/screenshots before sharing.
