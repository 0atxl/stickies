# Stickies v0.10.1

Local sticky notes for Windows x86_64 and supported Linux Wayland desktops. Package version: 0.10.1.

## Changes

- Playful now offers Wavy and Clean note edges in Settings. Wavy remains the default; the original footer remains available in every theme.
- Clean edges use smooth corners, a soft shadow and outlined checkboxes with finer completed-item strikes.
- Classic tabs have softer shading, rounded exposed corners, longer vertical labels and original title casing. Stacked retains its existing behavior.
- Playful notes with Classic tabs use a curved connector to the selected tab. Paper and Minimal keep their arrow.
- Unfocused individual-note titles return to the beginning. The connector uses current tab placement through text-size changes and strip rebuilds.

## Downloads and installation

**Windows x86_64:** extract the entire `stickies-windows-x86_64.zip`, then open `bin\stickies.exe`. Keep its runtime folders together. Rust and MSYS2 are not required. Quit before replacing an existing bundle. Notes and settings normally live separately under `%LOCALAPPDATA%\stickies`. Re-enable Launch at login if the bundle moves.

**Arch Linux x86_64:** install `stickies-0.10.1-1-x86_64.pkg.tar.zst` with `sudo pacman -U ./stickies-0.10.1-1-x86_64.pkg.tar.zst`, or update through AUR `stickies` or `stickies-bin`. Use an up-to-date Arch system and a Wayland compositor supporting Layer Shell v4+. Quit before upgrading. User notes and settings are retained.

**Cargo:** install native build prerequisites from the README, then run `cargo install stickies --version 0.10.1 --locked`. Desktop launcher/icon installation is a separate documented step.

Matching sources, original notices, build records and `SHA256SUMS` accompany the packages. These downloads are unsigned. Checksums detect changed bytes but do not provide a publisher signature.
