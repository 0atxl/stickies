# Stickies with MCP preview

This optional build lets a local MCP client find, read, create and update notes while Stickies is running. Access starts Off. Open Stickies Settings → MCP access to choose Read only or Read/write, then configure your client to launch `stickies-mcp`. [MCP setup and permissions](https://github.com/0atxl/stickies/blob/v0.10.3-mcp.1/packaging/README.md#model-context-protocol-mcp-companion)

**Back up your notes with Stickies closed before first launch.** The preview upgrades the database to schema 5. To return to standard v0.10.3, restore your pre-upgrade backup. [Standard v0.10.3 downloads](https://github.com/0atxl/stickies/releases/tag/v0.10.3)

- **Arch Linux x86_64**. Quit Stickies and install `stickies-mcp-0.10.3-1-x86_64.pkg.tar.zst` with `sudo pacman -U ./stickies-mcp-0.10.3-1-x86_64.pkg.tar.zst`. It replaces the standard package. The companion is `/usr/bin/stickies-mcp`. The edge requires Wayland Layer Shell v4 or newer.
- **Windows x86_64**. Extract the entire `stickies-mcp-windows-x86_64.zip`, run `bin\stickies.exe` and point your MCP client at `bin\stickies-mcp.exe`. Windows builds and packages have been verified. Windows MCP interaction is still unverified.

The Linux build includes the v0.10.3 safeguard against GTK theme blur on Stickies' full-screen edge windows. The original intermittent Hyprland symptom still lacks a confirmed reproduction. The Linux MCP checklist workflow passed in earlier focused testing. This preview uses the existing package build without running tests or launching the app.

The release provides matching source archives, original notices and `SHA256SUMS`. The downloads are unsigned.
