# Stickies v0.10.3

Package version: 0.10.3. This release prevents GTK window styles from requesting backdrop blur across Stickies' transparent full-screen Linux layer windows.

## Changes

- On Linux with GTK 4.22 or newer, both edge windows explicitly disable CSS backdrop filtering. The override applies only to these Stickies windows, including their collapsed state.
- Older GTK versions skip the property. System configuration and other applications' blur settings are unchanged.
- Windows packaging refreshes its reviewed GStreamer source and notice inputs to 1.28.9. Exact package versions and source checksum checks remain enforced.

This is preventive hardening after an intermittent full-screen blur report on GTK 4.24.1 and Hyprland 0.56.2. The original incident has not been reproduced or attributed conclusively to a client request or compositor behavior. This change does not claim to fix compositor-enforced blur or a compositor bug.

## Downloads and installation

**Windows x86_64:** download `stickies-windows-x86_64.zip`, extract the entire ZIP, then open `bin\stickies.exe`. Quit before replacing an existing bundle. This patch changes Linux behavior only.

**Arch Linux x86_64:** install `stickies-0.10.3-1-x86_64.pkg.tar.zst` with `sudo pacman -U ./stickies-0.10.3-1-x86_64.pkg.tar.zst`, or update through AUR `stickies` or `stickies-bin`. Quit before upgrading. User notes/settings are retained.

**Cargo:** install native build prerequisites from the README, then run `cargo install stickies --version 0.10.3 --locked`. Desktop launcher/icon installation is a separate documented step.

Matching sources, original notices, build records and `SHA256SUMS` accompany the packages. These downloads are unsigned. Checksums detect changed bytes but do not provide a publisher signature.

The focused visual regression remains pending: in an isolated Hyprland display at 1920x1080 and scale 1.25, with compositor blur enabled, the desktop outside Stickies must stay sharp through startup, reveal, docked notes and collapse. Capture the committed blur regions for both layer windows if the problem recurs. Online automated checks do not establish this visual result.

The Linux edge requires Wayland Layer Shell v4+. GNOME without Layer Shell, X11 and macOS are unsupported. Existing mixed-DPI/multi-monitor, login/session-end and accessibility verification limits remain.
