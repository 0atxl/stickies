Windows

x86_64

A ZIP with everything you need.

Download for Windows ↓

Extract the entire ZIP, then open bin\stickies.exe. Keep the extracted folders together. No Rust or MSYS2 installation needed.

Arch Linux

x86_64

For up-to-date Arch on compatible Wayland desktops.

Download Arch package ↓

Install the package with sudo pacman -U ./stickies-0.10.2-1-x86_64.pkg.tar.zst. Requires Wayland Layer Shell v4+.

Also on AUR: stickies source · stickies-bin binary

Release notes ↗SHA256 checksums ↗

Another Linux setup? Install from source with compatible native libraries and Wayland Layer Shell v4+. The Arch package is for Arch Linux only. macOS, X11, and GNOME without Layer Shell are not supported.
